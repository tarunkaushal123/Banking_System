#🏦 Banking System using Python & Streamlit

A beginner-friendly **Banking System simulation** built using Python and Streamlit.
This project was created to practice Python programming concepts and learn how to convert a simple programming problem into an interactive web application.

## 🚀 Project Overview
The application simulates basic banking operations such as:
* 💰 Checking account balance
* ➕ Depositing money
* ➖ Withdrawing money
* 📋 Viewing transaction history
* 🔄 Managing application state
* 🧭 Navigating through a Streamlit sidebar

The main objective of this project was not to build a production banking platform, but to understand how **Python logic can be integrated with Streamlit to create an interactive application.**

## 🛠️ Technologies Used
* **Python**
* **Streamlit**
* **Session State**
* **Data Structures**
* **Conditional Logic**
* **Functions**

## ✨ Features
1. 💳 Balance Management : Users can view their current account balance.
2. 💰 Deposit : Users can enter an amount and deposit it into their account.
3. 💸 Withdrawal :Users can withdraw money from their available balance.
4. 📜 Transaction History : The application maintains a record of transactions during the current session.
5. 📊 Interactive Interface : Streamlit provides a simple and interactive interface for performing banking operations.
6. 🧭 Sidebar Navigation: Different banking operations can be accessed through the sidebar.

## ▶️ How to Run the Project
1. Clone the repository
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```
2. Navigate to the project folder
```bash
cd Banking_System
```
3. Install the required libraries
```bash
pip install -r requirements.txt
```
4. Run the Streamlit application
```bash
streamlit run Banking_project.py
```

The application will open in your browser.
